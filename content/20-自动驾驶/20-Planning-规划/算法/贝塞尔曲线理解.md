float Circle(vec2 pixel, vec2 center, float radius)
{
    float d = length(pixel - center);
    return smoothstep(fwidth(d), .0, d - radius);
}
float LineSegment(vec2 pixel, vec2 a, vec2 b, float width)
{
    vec2 a2p = pixel - a, a2b = b - a;
    float t = clamp(dot(a2p, a2b) / dot(a2b, a2b), .0, 1.0);
    vec2 r = a + a2b * t;
    float d = length(r - pixel);
    return smoothstep(fwidth(d), 0., d - width);
}
vec2 Bezier1(vec2 start, vec2 controlPtr, float timeStep)
{
    return mix(start, controlPtr, timeStep);
}

我们考虑这么两个点，一个 \vec P_{01} 位于 \vec P_0, \vec P_1 之间，另一个 \vec P_{12} 位于 \vec P_1, \vec P_2 ，而我们可以用表示线段的公式去表示这两点（同时也是 \vec B_1(t) 的表达）
\vec P_{01} = (1-t) \vec P_0 + t \vec P_1 \\ \vec P_{12} = (1-t) \vec P_1 + t \vec P_2 \\ 去对比一下 \vec B_2(t) 和上面两个公式，不难发现我们可以进行分解了，只要写成
\vec B_2(t) = (1-t) \vec P_{01}+ t \vec P_{12} \\ \Rightarrow \vec B_2(t) = (1-t) [(1-t) \vec P_0 + t \vec P_1]+ t [(1-t) \vec P_1 + t \vec P_2] \\ \vec B_2(t) = (1-t)^2 \vec P_0 + (1-t)t \vec P_1+ t (1-t) \vec P_1 + t^2 \vec P_2 \\ \vec B_2(t) = (1-t)^2 \vec P_0 + 2(1-t)t \vec P_1 + t^2 \vec P_2 \\这就跟我们用公式推出来的东西是一样的了。所以这也揭示了贝塞尔曲线到底是啥：**其实是对几个点多次做线段**。看一点改变了的代码部分

其实就是我们的**二次贝塞尔**，而**它做的无非就是在两个一次贝塞尔的动点上画了条线段**。（嗅到递归的味道了吧）
很多好书其实在介绍贝塞尔的时候也会把它写成递归形式，来展示它的含义。比如《3D游戏与计算机图形学中的数学方法》一书中就是写成
B_{n, k}(t) = {}^nC_k\ t^k (1-t)^{n-k} \\ \Rightarrow B_{n, k} = (1-t)B_{n-1, k-1} + t B_{n-1, k} \\
而三次贝塞尔可能是被使用得最多的一种形式，但如果你了解了前面两次，那么这次就不会感到迷茫了。当 n=3 ，考虑（ \vec P_0, \vec P_1, \vec P_2, \vec P_3 ）四个点。再考虑三个点，一个 \vec P_{01} 位于 \vec P_0, \vec P_1 之间，一个 \vec P_{12} 位于 \vec P_1, \vec P_2 ，一个 \vec P_{23} 位于 \vec P_2, \vec P_3 之间，这三个点都符合一次贝塞尔。再考虑两个点，一个 \vec P_{012} 位于 \vec P_{01}, \vec P_{12} 之间，一个 \vec P_{123} 位于 \vec P_{12}, \vec P_{23} 之间，这两点也符合一次贝塞尔，而这就相当于 \vec P_{01}, \vec P_{12}, \vec P_{23} 之间符合二次贝塞尔。而这就是所谓的三次贝塞尔。听着像绕口令，来看看代码
