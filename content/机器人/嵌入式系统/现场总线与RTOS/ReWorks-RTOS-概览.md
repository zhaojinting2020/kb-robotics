# ReWorks RTOS 概览

> 原文标题：国产嵌入式实时操作系统 Reworks 全接触（蒋祥刚，华东计算技术研究所）

ReWorks/ReDe 是中国电子科技集团第 32 所（华东计算技术研究所）自主研制的**嵌入式实时操作系统 + 集成开发环境**平台，适用于 x86, PowerPC 等多种硬件，最小配置可小于 100 KB.

## 产品组成

| 组件 | 说明 |
|------|------|
| **ReWorks RTOS** | 兼容 VxWorks 的实时内核 |
| **ReDe IDE** | 设计 / 开发 / 调试 / 仿真一体化环境 |
| **实时中间件** | 屏蔽 OS 与网络差异，提供 CORBA 等支撑服务 |
| **图形界面** | 轻量级 GUI，支持中文输入与 FrameBuffer 加速 |

## ReWorks 内核特点

- 自主研制, 拥有全部源码
- 微内核, 可裁剪, 可扩充（最小 < 100 KB）
- 强实时：响应时间约 **15 μs**
- **VxWorks 兼容层**：应用层源代码级, 驱动层目标码级兼容
- 任务管理：优先级抢占 + 轮转调度
- IPC：消息队列, 事件, 信号量, 异步信号
- 内存：区域与分区管理
- 文件系统：兼容 MS-DOS
- 时钟：微秒级高精度
- 速率单调（Rate Monotonic）管理
- 网络：TCP, UDP, IP, ICMP, ARP 等
- 符合 **POSIX 1003.1B** 实时扩展

## 集成开发环境（ReDe）

- 宿主平台：Windows NT/2000/XP
- C/C++ 交叉编译
- 可视化系统配置, 项目管理
- 源码级远程调试：任务, 内存, 寄存器, 变量在线查看
- 指令级目标仿真：无 BSP / 目标硬件即可在宿主机运行目标代码
- 与第三方 CASE 工具 **Rhapsody** 无缝集成，支持 UML 建模

## 中间件与 GUI

**中间件**：符合实时/嵌入式 CORBA；支持定位, 自动发现, 即插即用与系统重构；对用户屏蔽硬件, 网络, OS, 语言差异。

**GUI**：所见即所得开发工具；控件可扩展；16 位色高分辨率；多种中文输入法；点阵/矢量字体；FrameBuffer 加速；API 兼容 Windows / X-Window 风格。

## 应用开发模式

ReWorks 提供 **VxWorks 兼容接口**，便于现有系统移植：

- **应用层**：源代码级兼容
- **驱动层**：目标代码级兼容

两种开发路径：

1. **直接编码**：传统 C/C++ 开发
2. **模型驱动**：与 Rhapsody 等 CASE 工具对接——UML 建模 → 仿真验证 → 自动生成代码

### 移植流程（概念）

原有 VxWorks 应用经接口适配后，在 ReDe 中重新配置, 编译, 调试，再下载到 ReWorks 目标板运行（原文含流程图）。

## ReDe 工具链要点

| 工具 | 功能 |
|------|------|
| **XML 核心配置** | 按应用需求裁剪内核组件（FS, IPC, 网络, 图形等）；与工程配置联动生成 Makefile |
| **工程管理** | 树状文件管理；支持 c/cpp/idl/java/asm；类分析器快速定位成员 |
| **编辑器** | 语法高亮, 模板, 书签；编译错误双击定位 |
| **编译** | 基于 GNU 工具链改造；支持 XScale, ARM, PowerPC 等交叉编译 |
| **调试** | 中文 GUI；源码/汇编单步；断点；变量/寄存器/内存/任务/栈；串口/网络/JTAG/BDM；远程与仿真调试 |
| **目标仿真器** | 无 BSP 即可开发；支持汉字, 多分辨率图形, 磁盘映像, 键鼠/时钟/网络仿真 |
| **诊断分析** | 周期性监视任务, 信号量, 消息队列, 内存分区, 定时器等；事后分析失败原因；发现性能瓶颈与资源冲突 |
| **第三方集成** | UML 建模, 配置管理, 插桩测试与覆盖率分析 |

## 应用前景

ReWorks 已成功应用于船舶电子, 车载导航等领域；面向信息家电, 工业控制等大规模嵌入式市场，具备自主知识产权与持续技术支持能力。
