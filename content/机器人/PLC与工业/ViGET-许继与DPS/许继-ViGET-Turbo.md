# 许继 ViGET Turbo

要点：
- **ViGET Turbo**：许继 PLC **组态编程与调试 IDE**（2026-06 版索引）。
- 功能：IEC 61131-3 编程, 硬件组态, 编译下装, 在线监控, 库管理, 趋势与诊断。
- 面向 SC500/GLE 等系列；支持 LD/ST/FBD/SFC 及自定义功能块。
- 飞书 base 表为版本/链接索引；详细操作见 **05 功能块与工具链** 与 **10 项目调试** 章节。典型工作流创建项目 → 设备组态 → 编程 → 仿真/编译 → 以太网下载 → 在线调试
