# 工业通信架构与选型

工业通信的关键不是协议名称，而是用合适的网络在规定时间内、以可诊断和可维护的方式交付正确数据。选型必须同时考虑实时性、拓扑、设备生态、信息模型和运维边界。

## 分层架构

现场层连接传感器、执行器与驱动；控制层连接 PLC、远程 I/O 和运动设备；信息层连接 HMI、SCADA、MES 或数据平台。现场总线和实时工业以太网主要服务控制层的确定性交换；OPC UA 更适合跨平台、带语义的信息集成。它们常常共存，而非互相替代。

## 协议选型的核心问题

先回答五个问题：谁是控制者、数据多久必须到达、是否需要多轴同步、拓扑和布线条件如何、故障后如何诊断和降级。Modbus 适合简单、兼容性优先的设备接入；PROFIBUS 面向传统现场总线；PROFINET 适合分布式 I/O 和工业以太网集成；EtherCAT 强于高同步运动控制；CANopen 适合 CAN 生态的设备网络；OPC UA 用于上层互操作、数据建模和安全访问。

## 数据质量与时间

数据点应定义单位、量程、时间戳、质量位和失联值。控制闭环关注端到端延迟、抖动和丢包处理；监控系统关注数据完整性、历史一致性和访问权限。不能以普通 TCP 连通性替代实时性能验证。

## 网络与安全设计

IP 地址、设备名、VLAN、端口、冗余和时间同步需要在设计阶段固定。网络分区、最小权限、账户管理、补丁策略和日志留存是工业系统的基本措施。远程访问应经由受控通道，避免直接暴露控制网段。
