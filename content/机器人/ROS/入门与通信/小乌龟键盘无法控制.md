# 小乌龟键盘无法控制

初学 ROS 时常用 turtlesim 小乌龟做示例。完整启动需要三个终端，**每条命令各占一个终端**（命令会占用当前终端）：

```bash
# 终端 1：启动 ROS 核心
roscore

# 终端 2：打开小乌龟窗口
rosrun turtlesim turtlesim_node

# 终端 3：键盘控制小乌龟
rosrun turtlesim turtle_teleop_key
```

## 键盘无响应的常见原因

`turtle_teleop_key` 通过终端读取按键。**必须把鼠标焦点放在运行 `turtle_teleop_key` 的终端上**，而不是小乌龟图形窗口。按常规习惯往往会先点中小乌龟窗口，此时在窗口里按方向键不会有任何反应；切回第三个终端后再按方向键即可控制。
