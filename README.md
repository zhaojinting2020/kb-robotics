# 机器人与自动驾驶

个人机器人与自动驾驶学习库（Obsidian vault）。建议先看 MOC，再按编号目录下钻。

仓库：https://github.com/zhaojinting2020/kb-robotics

写作：飞书改正文 → Cursor 拉取到本仓 → Obsidian 审链 → 推 GitHub。

## 快速开始

```bash
git lfs install
git clone https://github.com/zhaojinting2020/kb-robotics.git
cd kb-robotics
```

用 Obsidian 打开本仓库根目录作为 vault；启动页即本文件。
